接入与安全说明

• 本系统使用真实 Tool-Calling 查询 ECS 端 SQLite 遥测历史，严格杜绝虚构未接入传感器数据与未标定照度。

• API Key 严格保存在 ECS 云服务器 root-only 环境文件（/etc/project51-classroom/llm-agent.env），浏览器不持有私钥，安全不泄露。

• 如需切换平台或更换 Key，请在本地终端运行 python pipeline/provision-llm-env.py 进行无落盘安全配置。
